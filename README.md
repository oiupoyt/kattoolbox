# kattoolbox

Free, fast, browser-based developer tools. No sign-up. No data collection.

**Live →** *coming soon*

## Tools

- JSON Formatter & Validator
- Markdown Preview
- Base64 Encode/Decode
- URL Encode/Decode
- HTML Entity Encode/Decode
- JWT Decoder
- UUID Generator
- Lorem Ipsum Generator
- Hash Generator (SHA-1/256/384/512)
- QR Code Generator
- Password Generator
- Unix Timestamp Converter
- Color Converter (HEX/RGB/HSL)
- Number Base Converter
- Word & Character Counter
- Regex Tester
- Text Diff Checker
- Case Converter
- CSS Gradient Generator
- CSS Box Shadow Generator

## Stack

Next.js · TypeScript · Tailwind CSS · Static Export

## Run locally

```bash
npm install
npm run dev
```
