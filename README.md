# kattoolbox

Free, fast, browser-based developer tools. No sign-up. No data collection.

**Live →** *coming soon*

## Tools (30)

**Formatters** — JSON Formatter, Markdown Preview, SQL Formatter, XML Formatter

**Encoders** — Base64, URL Encoder, HTML Entities, JWT Decoder

**Generators** — UUID, Lorem Ipsum, Hash, QR Code, Password

**Converters** — Timestamp, Color, Number Base, JSON→CSV, CSV→JSON

**Text Tools** — Word Counter, Regex Tester, Diff Checker, Case Converter

**CSS Tools** — Gradient Generator, Box Shadow, Px↔Rem Converter

**Web Tools** — Meta Tag Generator, Slug Generator, Cron Parser, Image→Base64, Placeholder Image

## Stack

Next.js · TypeScript · Tailwind CSS · Static Export

## Run locally

```bash
npm install
npm run dev
```
