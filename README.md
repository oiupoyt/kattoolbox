# kattoolbox

Browser-based file and developer utilities. All processing occurs locally on the client without uploading files to any external server.

↗ [toolbox.oiupoyt.space](https://toolbox.oiupoyt.space)

## Tools

### Files & Media
- **File Shrinker**: Compress images to target thresholds (Discord 10MB/8MB, Gmail 25MB, web formats).
- **EXIF & GPS Scrubber**: Inspect camera metadata and remove location tags from photos.
- **PDF Toolkit**: Merge, split, extract pages, rotate documents, and convert images to PDF.
- **Image Redactor**: Black out or pixelate sensitive sections of images.

### Developer Utilities
- **Formatters**: JSON, Markdown, SQL, XML
- **Encoders**: Base64, URL, HTML Entities, JWT
- **Generators**: UUID v4, Lorem Ipsum, Hash (MD5, SHA-1, SHA-256, SHA-512), QR Code, Password
- **Converters**: Unix Timestamp, Color (HEX/RGB/HSL), Number Base, JSON / CSV
- **Text**: Word Counter, Regex Tester, Diff Checker, Case Converter
- **CSS**: Gradient Generator, Box Shadow, Px to Rem
- **Web**: Meta Tag Generator, Slug Generator, Cron Parser, Image to Base64, Placeholder Image
